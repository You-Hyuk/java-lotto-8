# java-lotto-precourse

## 🔎 구현 기능

***


#### 입력
- [x] 사용자로부터 구입 금액을 입력받는다.
- [x] 사용자로부터 당첨 번호를 입력받는다.
- [x] 사용자로부터 보너스 번호를 입력받는다.
#### 입력값 파싱
- [x] 구입 금액 입력을 숫자(long)로 파싱한다.
- [x] 당첨 번호 입력을 숫자 리스트로 파싱한다.
- [x] 보너스 번호 입력을 숫자(int)로 파싱한다.
- [x] 숫자로 파싱하는 과정에서 숫자가 아닌 입력을 검증한다.
#### 입력값 검증
- [x] 구입 금액 입력이 1000원 단위로 나누어 떨어지는지 검증한다.
- [x] 당첨 번호 입력 중 번호가 1 ~ 45 사이의 숫자인지 검증한다.
- [x] 당첨 번호 입력 중 번호가 6개인지 검증한다.
- [x] 당첨 번호 입력이 쉼표(,)로 구분되었는지 검증한다.
- [x] 당첨 번호 입력이 쉼표(,)로 끝나는지 검증한다.
- [x] 당첨 번호 입력 중 숫자들이 중복되는지 검증한다.
- [x] 보너스 번호 입력이 1 ~ 45 사이의 숫자인지 검증한다.
#### 출력
- [x] 발행한 로또 수량 및 번호를 출력한다. 번호는 오름차순으로 출력한다.
- [x] 로또 당첨 내역을 출력한다.
- [x] 로또의 총 수익률을 출력한다.
#### 로또 발행
- [x] 로또 구입 입력에 따른 개수만큼 6개의 무작위 번호를 가진 로또를 발행한다.
#### 로또 번호 검증
- [x] 로또 번호에 중복된 숫자가 있는지 검증한다.
- [x] 로또 번호가 6개의 숫자로 이루어져 있는지 검증한다.
#### 로또 당첨
- [x] 각 로또의 번호와 당첨 번호의 일치 개수를 확인한다.
- [x] 보너스 번호를 포함한 로또의 당첨 여부를 확인한다.
- [x] 해당 유저의 로또 총 수익률을 계산한다.

## ✔ 테스트

***
### ⭕ 성공
#### 입력값 검증
- [x] 구입 금액 입력이 1000원 단위로 나누어 떨어지는 숫자이다.
- [x] 당첨 번호 입력이 쉼표(,)로 구분된 1 ~ 45 사이의 6개의 숫자이다.
- [x] 보너스 번호 입력이 숫자이며 1 ~ 45 사이의 숫자이다.

#### 로또 번호 검증
- [x] 로또가 6개의 중복되지 않은 번호를 가지고 있다.

#### 로또 발행
- [x] 발행된 로또 번호의 출력이 오름차순으로 정렬된다.
- [x] 구입 금액 입력에 따른 개수 만큼 로또가 발행된다.

#### 로또 당첨
- [x] 로또 번호와 당첨 번호가 1개 일치하는 경우 당첨되지 않는다.
- [x] 로또 번호와 당첨 번호가 2개 일치하는 경우 당첨되지 않는다.
- [x] 로또 번호와 당첨 번호가 3개 일치하는 경우 5등이 당첨된다.
- [x] 로또 번호와 당첨 번호가 4개 일치하는 경우 4등이 당첨된다.
- [x] 로또 번호와 당첨 번호가 5개 일치하며 보너스 번호가 일치하지 않는 경우 3등이 당첨된다.
- [x] 로또 번호와 당첨 번호가 5개 일치하며 보너스 번호가 일치하는 경우 2등이 당첨된다.
- [x] 로또 번호와 당첨 번호가 6개 일치하는 경우 1등이 당첨된다.
- [x] 총 수익률을 계산한다.

### ❌ 실패 (예외 발생)
#### 입력값 검증
- [x] 구입 금액 입력이 숫자가 아닌 경우
- [x] 구입 금액 입력이 1000원 단위로 나누어 떨어지지 않는 경우
- [x] 당첨 번호 입력 중 번호가 숫자가 아닌 경우
- [x] 당첨 번호 입력 중 번호가 1 ~ 45 사이의 숫자가 아닌 경우
- [x] 당첨 번호 입력 중 번호가 6개가 아닌 경우
- [x] 당첨 번호 입력이 쉼표(,)를 기준으로 구분되지 않는 경우
- [x] 당첨 번호 입력이 쉼표(,)로 끝나는 경우
- [x] 당첨 번호 입력 중 숫자들이 중복되는 경우
- [x] 보너스 번호 입력이 숫자가 아닌 경우
- [x] 보너스 번호 입력이 1 ~ 45 사이의 숫자가 아닌 경우

#### 로또 번호 검증
- [x] 로또 번호가 6개보다 적은 숫자로 구성된 경우
- [x] 로또 번호의 개수가 6개가 넘어가는 경우
- [x] 로또 번호 중 중복된 숫자가 존재하는 경우
